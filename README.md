**Technologies:** Python · FastAPI · LLMs · Ollama · Qdrant · PostgreSQL · Streamlit

A legal AI application designed to retrieve relevant information from legal documents and generate context-grounded responses.

- Built document-ingestion workflows for extracting and processing unstructured legal content.
- Implemented text chunking, embeddings, vector search, and contextual retrieval.
- Integrated LLMs with Qdrant and PostgreSQL for legal knowledge retrieval.
- Developed backend APIs and an interactive interface for legal question answering.
- Explored situation analysis, timeline generation, risk indicators, and missing-information identification.

- Worked on inference workflows for infrastructure-related image analysis.
